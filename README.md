# Guild Hub Classic

Рабочий гильдейский аддон для **World of Warcraft Classic Era**. Текущая
разработка и тестирование ведутся только для Era. Архитектура отделяет игровое
API от модели данных, чтобы после официального анонса следующей ветки Classic
(условно «Classic Plus») оценить перенос без переписывания ядра.

## Состояние

Версия `0.2.0-alpha.1` закладывает локальную базу, права по рангу гильдии,
обмен данными, шесть разделов интерфейса и изолированный режим одиночной
проверки.

## Установка

1. Закройте World of Warcraft.
2. Скопируйте папку `GuildHubClassic` в
   `_classic_era_\Interface\AddOns\`.
3. Включите **Guild Hub Classic** в списке модификаций.
4. Используйте `/gh` или `/guildhub`.

Дополнительные команды: `/gh sync`, `/gh version`, `/gh reset`,
`/gh settings`, `/gh demo`.

История решений и проверок ведётся в `docs/DEVELOPMENT.md`.
